日语精听隐私政策

更新日期：2026 年 10 月 26 日

日语精听是一款用于在 YouTube 视频页面学习日语字幕的 Chrome 扩展。本政策说明扩展处理哪些数据、数据保存在哪里，以及用户如何管理这些数据。

处理的数据与用途

  • 在用户打开有日语字幕的 YouTube 视频时，扩展读取当前视频的标题、视频 ID、播放位置和日语字幕，用于逐句显示、播放控制、假名标注与本地查词。
  • 用户主动收藏字幕时，扩展保存所选字幕、时间位置及视频信息，以便回看。
  • 用户主动保存学习笔记时，扩展保存所选词语、语法或其他学习内容。
  • 用户主动请求 AI 解析时，扩展保存该次解析结果，方便后续查看。
  • 用户设置的 AI 接口地址、模型名称和 API Key 保存在本机的扩展存储中，用于执行其主动发起的 AI 请求。API Key 不通过 Chrome Sync 同步。

上述收藏、笔记、AI 记录和设置保存在 chrome.storage.local。开发者目前没有用于接收或同步这些记录的服务器，也不在扩展中接入广告或行为分析服务。

对外发送

扩展只在用户主动点击“AI 解析”或“测试连接”时联系用户自己填写并授权的 HTTPS AI 服务商。AI 解析请求包含当前字幕句及相邻句的文本、模型名称和用户填写的 API Key；测试连接请求不包含字幕文本。该服务商对收到的数据的处理受其自身条款和隐私政策约束。请在填写 API 地址前确认服务商是否符合您的要求。扩展不会将这些请求发送到开发者服务器。

扩展在用户正在浏览的 YouTube 页面中获取该视频的字幕。与 YouTube 的通信受 YouTube 自身的服务和隐私政策约束。

数据保存、导出与删除

收藏、笔记和 AI 记录会保留在当前浏览器的扩展本地存储中，直到用户逐条删除或卸载扩展。用户可以在设置页导出 JSON 备份，再通过导入功能恢复。备份文件保存在用户选择的本地位置；默认不包含 API Key。只有用户主动勾选“备份文件包含明文 API Key”时，导出的 JSON 才会包含该 Key。包含 Key 的文件应妥善保管。

用户可以在设置页清除 AI 配置；卸载扩展将删除该浏览器配置下的扩展本地数据。清除浏览器缓存与卸载扩展是不同的操作。扩展没有跨设备自动同步功能。

数据使用限制

本扩展处理数据只为提供用户所请求的日语学习功能及其必要的运行用途。不会出售用户数据，也不会将用户数据用于个性化广告。对通过 Chrome 扩展权限获得的信息的使用遵守 Chrome Web Store 用户数据政策及其 Limited Use 要求。
